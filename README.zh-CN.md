# XREAL Windows 稳屏 0.1.1

Air 2 Ultra 的 Windows x64 原型：把一台 Windows 显示器的桌面及普通应用画面，显示为眼镜中的 3DoF 悬停屏幕。无需 Android 手机或 Android Server。

## 启动

1. 将眼镜接到支持 DP 视频与 USB 数据的 USB-C 接口，保持电脑内屏为主屏。关闭占用眼镜的其他程序。
2. 打开 `XrealStableScreen.exe`，点击“连接 / 读取姿态”，等待显示“标定已读取 · 3DoF 姿态有效”。
3. 点击“切换 SBS 60Hz”。程序发送与 Android 原生库一致的显示命令，随后用 Windows `SetDisplayConfig` 恢复扩展桌面；此过程会短暂黑屏。等候约 5 秒。
4. “桌面来源”选电脑内屏，“眼镜输出”选 **3840×1080** 的眼镜。点击“启动 3DoF 眼镜画面”。
5. 面向希望固定的位置，按 **Ctrl + Alt + R** 居中；**Ctrl + Alt + Esc** 停止。也可用控制面板按钮。

首次使用 0.1.1，请先把眼镜放在稳定桌面上，点击 **“静置校准（5秒）”**。有3秒准备时间，再连续采集5秒；看到“校准完成”后戴上并重新居中。校准期间不要转动眼镜，振动或移动会重新计时，45秒仍未成功则保留原值并提示重试。

这个按钮测量的是陀螺仪运行时零偏，普通“重新居中”不会校准零偏。校准参数会保存在同目录 `gyro-calibration.json`，按眼镜序列号及出厂标定数据匹配后载入。温度明显变化或再次出现缓慢漂移时可重新静置校准。此文件只适用于对应的那副眼镜，不包含在发布压缩包中。

鼠标键盘照常操作电脑。来源和眼镜输出必须是两个独立显示器，避免循环采集。若显示列表未及时更新，点“刷新显示器”后重新启动画面。此按钮会停止当前画面。

## 可调整项

- 屏幕大小 25%～150%，距离 0.5～5.0m；两项独立影响屏幕的视角大小。
- 垂直视场角 18°～40°，默认近似值 26°。改变视场角会改变转头的角度补偿比例，应缓慢转头与实物参照校准。
- 转头预测 0～20ms，默认 8ms；0 可与第一轮无预测版本对照。出现回弹时减小。预测只使用最近的角速度，最长 20ms、最多约 8.6°，不外推过期或无效姿态。
- 静态标定网格：排除桌面帧率因素，单独观察眼镜画面。
- 桌面预览：固定视角窗口，仅检查采集；不验证 3DoF。

参数在正常退出时保存到同目录 `settings.json`。点“保存诊断”生成 `diagnostic.json`；每秒的状态记录在 `runtime-metrics.jsonl`。

## 实现与范围

Windows 部分使用微软 HID/SetupAPI、DXGI Desktop Duplication、Direct3D 11 和 SetDisplayConfig。采集纹理在 GPU 内复制，姿态与桌面更新独立：桌面静止时仍持续按输出刷新率渲染。模式变化会停止画面并刷新显示列表；采集暂时失效时自动重建。

眼镜通信用的是从现有 Android 程序追出的控制/IMU 协议，不是把 ARM64 `.so` 当成 Windows DLL。6 条命令包已通过离线执行附件原生库的 `cmd_build_imu` / `cmd_build_sdk` 逐字节比对。IMU 标定读取、实际 USB 回包和数据流已在本机 Air 2 Ultra 验证。

姿态融合是本程序的陀螺仪积分、重力校正和显式静置零偏校准，尚未移植 XREAL 闭源跟踪、预测、畸变和异步重投影引擎。校准后的角速度同时用于积分和预测，避免预测仍然使用有偏数据。首次零偏必须通过点击校准获取；不设角速度死区，也不自动把屏幕拉回中心。光学投影暂用近似视场角和 63mm 双眼间距。受到系统保护的视频、UAC 安全桌面等内容可能无法采集。鼠标的传统 XOR 光标仅作近似合成。

“静止微调”默认开启，只在已完成一次校准后工作：滤波后的残余角速度小于约0.12°/秒、加速度稳定且持续3秒后，以5秒时间常数缓慢更新当前零偏；转头或加速度变化会暂停。这个方法可跟进较小的温度漂移，但IMU无法区分非常缓慢的恒定航向旋转与零偏。需要观察极慢转头时请关闭微调，手动静置校准仍有效。重力不能提供绝对航向参照，无法保证长期航向绝对无漂移。

## 验证情况

2026-11-04：用户已连接全功能 USB4、Air 2 Ultra，确认“正常 3DoF 显示，转头时略有延迟”。实测桌面 2560×1600 → 眼镜 3840×1080，采集与渲染约 60fps；5.01秒收到4997个有效IMU样本，约1000Hz。自动恢复扩展显示已在本机验证。加入预测后用户反馈延迟略有改善、快速转头仍有少量果冻效应，总体效果较为正确。眼镜显示的是主屏副本，用户确认文字方向正常。

`--self-test` 运行协议、数值、旋转、断流和 D3D 渲染检查，同时检查真实 DXGI 采集（需要交互桌面）；只保存网格测试图，不保存桌面图像。`--diagnose` 保存 HID 与显示器清单。测试统计不等于端到端延迟测量。

0.1.1 的新增检查包括：带偏置的十分钟静置模拟、温漂变化、缓慢真实转头、移动/振动时拒绝校准及失败保留旧值。模拟数值不是实机长期精度承诺。实机已验证静置校准保存及重启后按眼镜匹配载入。

0.1.1 在用户确认静置的61秒测量中，航向净变化约0.085°、区间最大差约0.097°。旧版对应问题的静置日志为16秒变化约6.1°。新版共32项自动检查及6条原生命令包比对通过；一分钟测量不能代表长期温度变化和佩戴运动后的稳定精度。

## 构建

源代码位于本仓库根目录，构建后的可执行文件位于 `dist/XREAL-StableScreen-v0.1.1`。

使用 Visual Studio 2022 C++ 工具链与 Windows SDK。运行本目录 `build.ps1`；添加 `-Test` 执行离线和桌面采集检查。默认静态链接 C++ 运行库，不需要安装 Python、Unity、.NET SDK 或替换 USB 驱动来运行成品。

参考：[微软桌面采集 API](https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/desktop-dup-api)、[微软显示配置 API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setdisplayconfig)、[ar-drivers-rs 协议参考（MIT）](https://github.com/badicsalex/ar-drivers-rs/blob/master/src/nreal_air.rs)。第三方许可见 `THIRD-PARTY-NOTICES.txt`。
